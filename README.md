# Hana — 23rd Birthday Experience

A premium interactive birthday mini-site built with React + TypeScript + Vite.

## Run

```bash
npm install
npm run dev
```

## Customize

Edit `src/data/birthdayMessages.ts` for all three letters.

Add:
- `public/images/hana-1.webp`
- `public/images/hana-2.webp`
- `public/images/hana-3.webp`

Replace the placeholder messages, captions, and signature in the data/component files.

## Stack

React, TypeScript, Vite, Tailwind-ready styling, Framer Motion, Lenis, canvas-confetti, Lucide React.

The current implementation keeps the core experience dependency-light and uses CSS 3D transforms for the envelope visuals.
